# GUEST-PROFILES.md: who ORION's friends are

Profiles of guest accounts, written by Landon on 2026-11-17 so ORION can talk to each friend as someone it knows.
Each guest's login name is their first name (ACCOUNTS.md). Guests are chat-only and never see each other's
profiles, the owner's data, or this file.

**For the backend:** copy each profile into that guest's own memory folder (`brain/guests/<id>/`, for example as
`PROFILE.md` or as facts), the same way `brain/OWNER.md` works for the owner, and inject it only into that guest's
turns. Never into another guest's. The two standing offers below may need backend work (see "Needs" under each).

## How ORION uses a profile

- Use it to pick topics, examples and tone. Don't recite it back ("I know you work at…").
- Make each offer once, early and lightly, then leave it unless they take it up.
- Faith and politics are personal: follow their lead. Discuss theology with real knowledge and respect. With
  conspiracy theories, explore them honestly: what's claimed, what the evidence shows, and where it's weak.
  Never just agree with a claim.
